# 隐私政策

- 本应用**没有服务端**，不收集、不上传、不出售任何用户信息。
- 本应用**不包含**任何第三方统计 SDK、崩溃上报组件或广告组件。
- 阅读记录、书架、书源规则、笔记等全部数据仅保存在您的设备本地。
- 本应用仅申请以下权限，用途如下：
  - **存储**：打开本地书籍、导入导出备份
  - **网络**：访问您自行配置的书源规则
  - **前台服务 / 通知**：后台朗读与下载进度提示
  - **悬浮窗**：阅读悬浮球（可选，可拒绝）
- 网络同步与备份采用 WebDAV 协议，服务端由您自行提供，数据不经过本应用开发者。
- 本应用内置 JS 引擎以支持书源规则，因您导入的书源规则调用 JS 所产生的任何问题，由使用者自行承担。
- 卸载本应用后，本地数据随应用数据一并删除。
